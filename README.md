# Data Science Lab – Digital Portal

A web-based **Data Science Lab Digital Portal** developed to organize laboratory experiments, Python programs, learning modules, and data science tools in one place.

## 🔗 Links

- **Live Website:** [https://poojithachowdarykotapati-beep.github.io/dslab/](https://poojithachowdarykotapati-beep.github.io/dslab/)
- **GitHub Repository:** [https://github.com/poojithachowdarykotapati-beep/DataScience](https://github.com/poojithachowdarykotapati-beep/DataScience)


## 📌 About the Project

The Data Science Lab Digital Portal provides a simple and interactive platform for students to learn Data Science concepts, explore experiments, write Python programs, and view program outputs. It is designed for the CSE – Data Science department at Mohan Babu University.

## ✨ Features

- **Dashboard:** Access the main sections of the Data Science Lab portal.
- **Learning Modules:** Explore Data Science learning materials and topics.
- **Experiments Hub:** Browse, organize, and execute 10 comprehensive laboratory experiments (including Web Scraping with Beautiful Soup, Customer Personality Clustering, and Text Emotion Detection).
- **Python Code Editor:** Write and execute Python programs directly in the browser.
- **Live Output:** View the output of Python programs in the console.
- **Pandas and NumPy Support:** Perform basic data analysis operations.
- **Sample Datasets:** Use available CSV datasets such as `students.csv`, `iris.csv`, and `data.csv`.
- **Custom CSV Upload:** Upload datasets for practical exercises.
- **Add and Edit Experiments:** Create and update experiment details and Python starter code.
- **Data Backup and Restore:** Export and restore saved portal data.
- **Student Profile:** Display student and academic details.
- **Responsive Interface:** Access the portal through supported desktop and mobile browsers.

## 💻 Python Compiler

The portal includes a browser-based Python execution environment powered by Pyodide. It supports Python programming and data analysis using compatible libraries such as Pandas and NumPy.

Students can write code, run programs, use sample datasets, and view the output without installing Python locally.

## 🚀 How to Use

1. Open the [Data Science Lab website](https://poojithachowdarykotapati-beep.github.io/dslab/).
2. Navigate to the Modules or Experiments section.
3. Select an experiment to explore its description and code.
4. Write or modify Python code in the compiler.
5. Click **Run Code & Get Output** to execute the program.
6. View the results in the console.
7. Use the available datasets or upload a custom CSV file for data analysis exercises.
